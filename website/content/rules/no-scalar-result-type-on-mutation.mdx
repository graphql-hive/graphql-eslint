[suggestions](https://eslint.org/docs/developer-guide/working-with-rules#providing-suggestions)

- Category: `Schema`
- Rule name: `@graphql-eslint/no-scalar-result-type-on-mutation`
- Requires GraphQL Schema: `true` [ℹ️](/docs/usage#providing-graphql-schema-optional)
- Requires GraphQL Operations: `false` [ℹ️](/docs/usage#providing-graphql-operations-optional)

Avoid scalar result type on mutation type to make sure to return a valid state.

## Usage Examples

### Incorrect

```graphql
# eslint @graphql-eslint/no-scalar-result-type-on-mutation: 'error'

type Mutation {
  createUser: Boolean
}
```

### Correct

```graphql
# eslint @graphql-eslint/no-scalar-result-type-on-mutation: 'error'

type Mutation {
  createUser: User!
}
```
