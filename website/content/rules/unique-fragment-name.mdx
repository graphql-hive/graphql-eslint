✅ The `"extends": "plugin:@graphql-eslint/operations-recommended"` property in a configuration file
enables this rule.

- Category: `Operations`
- Rule name: `@graphql-eslint/unique-fragment-name`
- Requires GraphQL Schema: `false` [ℹ️](/docs/usage#providing-graphql-schema-optional)
- Requires GraphQL Operations: `true` [ℹ️](/docs/usage#providing-graphql-operations-optional)

Enforce unique fragment names across your project.

## Usage Examples

### Incorrect

```graphql
# eslint @graphql-eslint/unique-fragment-name: 'error'

# user.fragment.graphql
fragment UserFields on User {
  id
  name
  fullName
}

# user-fields.graphql
fragment UserFields on User {
  id
}
```

### Correct

```graphql
# eslint @graphql-eslint/unique-fragment-name: 'error'

# user.fragment.graphql
fragment AllUserFields on User {
  id
  name
  fullName
}

# user-fields.graphql
fragment UserFields on User {
  id
}
```
