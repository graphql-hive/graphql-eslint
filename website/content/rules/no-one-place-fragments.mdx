- Category: `Operations`
- Rule name: `@graphql-eslint/no-one-place-fragments`
- Requires GraphQL Schema: `false` [ℹ️](/docs/usage#providing-graphql-schema-optional)
- Requires GraphQL Operations: `true` [ℹ️](/docs/usage#providing-graphql-operations-optional)

Disallow fragments that are used only in one place.

## Usage Examples

### Incorrect

```graphql
# eslint @graphql-eslint/no-one-place-fragments: 'error'

fragment UserFields on User {
  id
}

{
  user {
    ...UserFields
  }
}
```

### Correct

```graphql
# eslint @graphql-eslint/no-one-place-fragments: 'error'

fragment UserFields on User {
  id
}

{
  user {
    ...UserFields
    friends {
      ...UserFields
    }
  }
}
```
