- Category: `Schema`
- Rule name: `@graphql-eslint/require-nullable-result-in-root`
- Requires GraphQL Schema: `true` [ℹ️](/docs/usage#providing-graphql-schema-optional)
- Requires GraphQL Operations: `false` [ℹ️](/docs/usage#providing-graphql-operations-optional)

Require nullable fields in root types.

## Usage Examples

### Incorrect

```graphql
# eslint @graphql-eslint/require-nullable-result-in-root: 'error'

type Query {
  user: User!
}
```

### Correct

```graphql
# eslint @graphql-eslint/require-nullable-result-in-root: 'error'

type Query {
  foo: User
  baz: [User]!
  bar: [User!]!
}
```
